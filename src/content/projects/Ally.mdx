### Overview
ALLY is a streetwear brand that I'm currently building a web platform for, showcasing their products and collections. The platform is built using HTML5, CSS, and JavaScript, providing a responsive and interactive user experience. I do this to hone my skills software development and web design, while also contributing to the growth of a brand I believe in. The platform features a clean and modern design, with easy navigation and a focus on the products themselves. It also includes a contact form for inquiries and a blog section for updates and news. Overall, the ALLY web platform is a work in progress that I'm excited to continue developing and improving over time.
