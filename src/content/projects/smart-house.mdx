### Overview
The Smart House Automation System is an IoT-based project designed to monitor and control household devices through a web-based dashboard. The system allows users to remotely switch lights and power sockets on or off, while tracking energy consumption through a connected database.

Features Remote control of lights and power sockets through a web interface Real-time monitoring of device states Energy consumption tracking and storage in a database Device scheduling and automation User-friendly dashboard for system management Integration with microcontroller hardware for physical device control Technologies Used Python Flask HTML CSS JavaScript JSON Database ESP32 Microcontroller System Functionality.
In the project, the wiring connection was done from scratch on the wodden board seen in the video.
